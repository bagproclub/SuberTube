# SuberTube Research Notes — 2026-09-25

## Android WebView navigation

Android's WebView guidance states that normal WebView navigation can be intercepted with `WebViewClient.shouldOverrideUrlLoading`. The application can return `false` for URLs that should stay in WebView and can implement custom handling for selected URLs.

Reference: https://developer.android.com/develop/ui/views/layout/webapps/webview

The Android guidance also cautions against calling `loadUrl` directly from inside `shouldOverrideUrlLoading`. SuberTube therefore defers the local return navigation with `View.post`.

## Bundled local Web content

Android documents `WebViewAssetLoader` as the supported approach for serving app-bundled HTML/CSS/JavaScript through an HTTP(S)-style local origin.

Reference: https://developer.android.com/develop/ui/views/layout/webapps/load-local-content

## YouTube IFrame

The official YouTube player loads a specific video with `https://www.youtube.com/embed/VIDEO_ID`. Search inside an embedded player via `listType=search` is deprecated; the current no-API design therefore uses the real YouTube Search web surface for discovery and an official IFrame for playback after selecting a Video ID.

Reference: https://developers.google.com/youtube/player_parameters

## AndroidX WebKit

As of 2026-09-25, AndroidX WebKit stable is `1.17.1`. Version 1.17 added enhanced navigation capabilities, while 1.17.1 is a bug-fix release.

Reference: https://developer.android.com/jetpack/androidx/releases/webkit

## Android build toolchain

Android Gradle Plugin `9.4.0` (September 2026) supports up to API 37 and requires Gradle `9.6.0` and JDK `17` as the minimum/default compatibility pair. This project pins that toolchain in its build configuration.

Reference: https://developer.android.com/build/releases/agp-9-4-0-release-notes

## Picture-in-Picture

Android supports Picture-in-Picture from API 26 for compatible activities. PiP is a runtime capability and still requires device validation for the actual embedded-player behavior.

Reference: https://developer.android.com/develop/ui/views/picture-in-picture

## Security interpretation

URL reputation is only one security signal. A verdict such as `unknown` does not establish that an indicator is safe. SuberTube therefore combines URL reputation with source scanning, secret scanning, foreign-content scanning, URL allowlisting, regression testing, and release integrity checks.
